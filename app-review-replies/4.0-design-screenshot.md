# Guideline 4.0 — Design / Screenshot リジェクト返信テンプレ

## 📋 リジェクト概要

**Apple の言い分**: スクリーンショットが「誤解を招く」「実際のアプリと違う」「品質が低い」
「アプリプレビューと不整合」など。

**典型的なNGパターン**:
- スクショに実装されてない機能が映ってる
- スクショの UI が実機と大幅に違う
- スクショに他社ロゴ・写真・テキストの権利侵害がある
- スクショが意味不明 / 解像度が低い / 加工しすぎ
- "Coming soon" / "Beta" / 偽キャプション

## 🔧 コード側の修正

スクショを作り直す：

```bash
# ゆっくりエクソソーム の場合
npm run assets:store  # or
python scripts/icon-gen/make_screenshots.py
```

実画面ベースか、忠実なモックを使う。

## 📝 ASC 「App Reviewに返信」 欄にコピペするテキスト（日本語版）

```
App Review チームの皆様

スクリーンショットに関するご指摘ありがとうございます。

ご指摘いただいた点について、以下のとおり対応いたしました：

【修正内容】
- <該当スクショ>: <修正理由（実画面と一致しない、誤解を招く、等）>
- 全 <N> 枚のスクリーンショットを、実際にアプリで表示される画面と
  完全に一致する内容に差し替えました。
- <その他、加工の削減、注釈の明確化、など具体的な対応>

新しいスクリーンショットおよびビルドを近日中にアップロードしますので、
ご確認のほど宜しくお願いいたします。

宜しくお願いいたします。
```

## ✅ チェックリスト

- [ ] スクショに映る機能がすべて実装済みか
- [ ] UI / レイアウト / 文言が実機と一致するか
- [ ] 他社ロゴ / 著作権ある画像が映ってないか
- [ ] iPhone 6.7" / 6.5" の解像度（1290×2796 / 1242×2688）が正しいか
- [ ] ファイル名が `iphone-67-*` / `iphone-65-*` プレフィクスか（asc-screenshot-upload.mjs の要求）
