# Guideline 2.3.10 — Other Platform Reference リジェクト返信テンプレ

## 📋 リジェクト概要

**Apple の言い分**: アプリの description / keywords / screenshots / release notes に
「Android」「Google Play」「Play Store」など、**他社プラットフォームの名前** が含まれている。
App Store のメタデータには Apple/iOS 関連の言及のみが許容される。

**典型的なNGワード**:
- Android / Google Play / Play Store / Play Console
- Amazon Appstore / Galaxy Store
- 「ダウンロード: App Store / Google Play」のような両プラットフォーム並記
- スクショに「Get it on Google Play」バッジが映ってる

## 🔧 コード側の修正

```
store-assets/appstore/description-ja.txt
store-assets/appstore/keywords-ja.txt
store-assets/appstore/subtitle-ja.txt
store-assets/appstore/promotional-text-ja.txt
release-notes/CURRENT-ja.txt
```

これらのファイル内の他社プラットフォーム名を削除、または「スマホアプリ」等の中立表現に置換。

スクショ画像も Apple バッジ単独 or 中立アイコンのみに差し替え。
