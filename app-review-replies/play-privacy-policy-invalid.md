# Google Play — プライバシーポリシーが無効 リジェクト返信テンプレ

## 📋 リジェクト概要

**Google の言い分**: プライバシーポリシーが Google Play の要求を満たしていない。
典型的には以下のいずれかが欠けてる：

1. **収集するデータの種類**（具体的に何を記録するか）
2. **データの使用目的**
3. **データを共有する第三者**（無い場合は「無い」と明記）
4. **データを保持する期間**（具体的な期間 or トリガー）
5. **データを削除する方法**（ユーザーが手動で削除する手段）
6. **連絡先情報**（運営者名・メール）

特に **5. データを削除する方法** がよく抜けてる。
今回のゆっくりエクソソーム リジェクト (2026-06-03) もこれだった。

## 🔧 コード側の修正

### A. プライバシーポリシー専用ページを作る or 強化する

```
src/privacy/index.html  ← /about/ とは別にする
```

最低限以下のセクションを含める：

| セクション | 必須内容 |
|---|---|
| 1. 適用範囲 | アプリ名・サイト URL・運営会社名 |
| 2. 収集データ | 端末内保存データの種類リスト |
| 3. 使用目的 | 各データ種別の使用目的 |
| 4. 第三者共有 | 「しない」を明記 |
| 5. 保存場所・保持期間 | localStorage/IndexedDB、削除トリガー |
| 6. 削除方法 | アプリ内・端末設定・ブラウザ各経由の手順 |
| 7. 権限（カメラ/通知等） | 何にどう使うか・拒否方法 |
| 8. 子どもの情報 | 13歳未満の方針 |
| 9. ポリシーの変更 | 更新ルール |
| 10. 連絡先 | 運営者名・メールアドレス |
| 11. 適用法令 | 日本法 + GDPR/CCPA 配慮 |

### B. app.config.json に privacyUrl を反映

```json
{
  "contact": {
    "privacyUrl": "https://yukkuri-exosome.link/privacy/",
    "dataDeletionUrl": "https://yukkuri-exosome.link/privacy/#6-データの削除方法"
  }
}
```

### C. Play Console GUI で privacyUrl を更新

Play Console > アプリのコンテンツ > プライバシーポリシー の入力欄を `/privacy/` の URL に変更。
その後「変更を保存」 → 「公開の概要」 > 「変更を Google に送信して審査を受ける」。

## 📝 Google Play 「再審査請求」または「変更を Google に送信して審査を受ける」用テキスト

Play Console には Apple のような自由返信欄はなく、ボタンを押すだけが基本。
再審査請求テキストが必要な場合は以下：

```
プライバシーポリシーのご指摘ありがとうございます。

ご指摘いただいた「データの削除方法が明記されていない」「データの保存・保持期間が伝わっていない」
の2点について、以下の対応をいたしました。

【新しいプライバシーポリシーURL】
https://yukkuri-exosome.link/privacy/

【追加した内容】
- 「5. データの保存場所と保持期間」セクションで、データが端末内のみに保存され、
  保持期間は利用者の削除操作・アンインストール・ストレージクリアまでであることを明記
- 「6. データの削除方法」セクションで、以下3経路の削除方法を具体的に記載
  (1) アプリ内の「すべてのデータを削除」ボタン経由
  (2) iOS/Android の端末設定経由
  (3) Web ブラウザのストレージクリア経由
- 「2. 当社が収集するデータの種類」セクションで、端末内データの種類・サーバー収集なし
  ・収集しないデータ（IDFA、位置情報、行動分析等）を網羅的に明記

本アプリは設計上、サーバーへのデータ送信を一切行わず、すべてのデータは利用者の端末内
(localStorage/IndexedDB) のみに保存されます。第三者提供・広告SDK・分析SDKもありません。

ご確認のほど宜しくお願いいたします。
```

## ✅ チェックリスト

- [ ] `/privacy/` ページが Google 要求 6 項目すべてを含んでいるか
- [ ] 「データの削除方法」が **3つ以上の具体的な経路**で書かれているか
- [ ] 「データの保持期間」が **明確なトリガー**（削除/アンインストール等）で書かれているか
- [ ] 連絡先メールアドレスが書かれているか
- [ ] Vercel で本番URLでアクセス可能か（`curl https://yukkuri-exosome.link/privacy/` で 200）
- [ ] Play Console GUI で privacyUrl を `/privacy/` に変更したか
- [ ] Play Console GUI で「公開の概要 > 変更を Google に送信」をクリックしたか
