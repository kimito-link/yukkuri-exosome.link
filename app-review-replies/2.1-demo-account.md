# Guideline 2.1 — App Completeness / Demo Account リジェクト返信テンプレ

## 📋 リジェクト概要

**Apple の言い分**: 「ログインなしではアプリの中身が見えない」もしくは
「デモアカウントの認証情報が提供されていない」。

**よくあるシナリオ**:
- ログイン必須のアプリで、デモアカウントが ASC に登録されてない
- デモアカウントは登録してあるが、ログインできない（パスワード変更後など）
- Apple のレビュアーが指定の手順でアプリの中身を確認できない

## 🔧 ケース別対応

### ケースA: このアプリにアカウントシステムが無い場合（ゆっくりエクソソーム該当）

このアプリは **アカウント不要・全データ端末内** のため、デモアカウントは不要。
ただし、その旨を Reviewer Notes に明記する必要がある。

### ケースB: ログイン必須のアプリ（リバースハック等該当）

- ASC > App Information > App Review > Demo Account 欄にデモ認証情報を登録
- ワークフローの `IOS_REVIEW_DEMO_USERNAME` / `IOS_REVIEW_DEMO_PASSWORD` secrets を更新
- 実際にログインできることを `verify-reviewer-account.mjs` で事前確認

## 📝 ASC 「App Reviewに返信」 欄にコピペするテキスト（ケースA：アカウントなしアプリ）

```
App Review チームの皆様

ご確認ありがとうございます。

<アプリ名> はアカウント登録を一切必要としないアプリです。
ログイン画面はなく、アプリを起動するとすぐに <初期画面名> が表示され、
すべての機能 (<タブ列挙>) がインストール直後から使用可能です。

データはすべて利用者の端末内 (localStorage / IndexedDB) のみに保存され、
サーバー送信・第三者提供・広告 SDK はありません。

レビュー担当者向けメモ（"App Review Information > Notes"）にも、
このアプリにはアカウントシステムがない旨を記載しております。

何かご不明な点があればお知らせください。
お手数をおかけしますが、ご確認のほど宜しくお願いいたします。
```

## 📝 ケースB（ログイン必須アプリ）

```
App Review チームの皆様

ご指摘いただきありがとうございます。
デモアカウントの動作確認のうえ、以下の認証情報を改めて登録いたしました：

Username: <demo username>
Password: <demo password>

実際にログイン可能な状態であることを確認済みです。

新しいビルドを近日中にアップロードしますので、ご確認のほど宜しくお願いいたします。
```

## ✅ チェックリスト

- [ ] アカウントなしアプリは、Reviewer Notes に「No login required」と明記したか
- [ ] ログイン必須アプリは、デモアカウントが実際に動作するか
- [ ] ワークフローの secrets が最新か
- [ ] verify-reviewer-account.mjs を実行して検証したか
