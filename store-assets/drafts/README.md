# ストア掲載の下書き（未申請）

ここは次にストアへ出すときの文面と、差し替え済みスクリーンショットの説明です。
この変更では申請も、バージョン番号の変更もしていません。

- 説明文の正本: `store-assets/appstore/description-ja.txt`
- プロモーションテキスト: `store-assets/appstore/promotional-text-ja.txt`
- Google Play の詳しい説明: `store-assets/play/listing-ja.txt`
- 短い説明は `app.config.json` の `businessModel.summaryJa`（80字以内。Play の short description に使われる）
- リリースノート下書き: `store-assets/drafts/release-notes-ja.txt`
  - `release-notes/CURRENT-ja.txt` はまだ古いスプラッシュの文面のままです。申請スクリプトがそれを送るので、承認前に上書きしていません。

スクリーンショット（差し替え済み。アップロードはしていません）:

- iPhone 6.7インチ 1290×2796: `iphone-67-1-today` から `7-me`（2 がロンジェビティ、3 がつながり・生きがい）
- iPhone 6.5インチ 1242×2688: 同じ順の `iphone-65-*`（申請スクリプトが 6.5 も要求するため）
- Google Play 1080×1920: `play-1-today` から `play-7-me`
- 古いファイル名（`iphone-67-2-care` など）は残すと申請時に混ざるので削除しています

公開中の App Store はバージョン 0.2.0 です。掲載スクショは、いまのアプリ（ログイン、ロンジェビティの「今週の手ごたえ」、3人組のホーム）と違います。掲載の差し替えは、バイナリを上げなくてもメタデータの提出になります。ここではファイルを用意しただけです。
