プライバシーポリシー

「ゆっくりエクソソーム」（以下「本アプリ」）は、利用者の方々のプライバシーを最大限尊重して設計されています。
本アプリは アカウント登録不要、すべてのデータは利用者の端末内のみに保存 される設計で、サーバーへのデータ送信や第三者への提供は一切行いません。

最終更新日: 2026年6月3日 / 運営: Kimito-Link（株式会社ベストトラスト）

1. 適用範囲

本ポリシーは、Kimito-Link（株式会社ベストトラスト、以下「当社」）が提供する以下のサービスに適用されます。

  • iOS / Android スマートフォン向けアプリ「ゆっくりエクソソーム」（App Store / Google Play で配信）
  • 本アプリの公式ウェブサイト https://exosome.kimito.link/

2. 当社が収集するデータの種類

当社は、サーバー上で利用者の個人情報を一切収集しません。本アプリの設計上、以下に該当します。

2-1. アプリ内で利用者の端末に保存されるデータ

本アプリは、以下のデータを 利用者の端末の内部ストレージ（localStorage および IndexedDB）のみに保存 します。これらのデータはサーバーには送信されず、当社およびその他の第三者はこれらのデータにアクセスできません。

  • セルフケア記録: 肌のセルフチェックスコア、疲労回復度、ケア項目のチェック
  • サプリ・点滴の記録: 利用者が記録した栄養素・施術の摂取履歴
  • クリニック関連メモ: 利用者が任意で入力する医療機関への質問メモ
  • ビフォーアフター写真: 利用者が任意で撮影または選択した記録写真（IndexedDB に Blob 形式で保存）
  • 設定情報: 通知設定、リマインダー時刻、選択中のキャラクター
  • 進捗データ: 連続記録日数、累計日数、レベル、EP、バッジ獲得状況、クイズスコア

2-2. サーバーから取得する情報

本アプリは、起動時に公開ウェブサイト https://exosome.kimito.link/ のコンテンツ（HTML / CSS / JavaScript / 画像 / フォント）を表示用に取得します。これらは すべての利用者に共通の静的コンテンツ であり、個人を特定する情報を含みません。

2-3. 当社が収集しないデータ

本アプリは以下のデータを 一切収集しません。

  • 氏名・メールアドレス・電話番号などの個人情報
  • 位置情報（GPS データ）
  • 連絡先・カレンダー
  • 利用者の IP アドレス、端末識別子（IDFA、Android Advertising ID 等）
  • アプリの利用ログ、行動分析データ、クラッシュレポート
  • サードパーティ広告 SDK 経由のあらゆるデータ

3. データの使用目的

端末内に保存されたデータは、利用者本人がアプリの機能を利用するための目的（記録・閲覧・比較・進捗確認）のためにのみ、利用者の端末内で処理されます。当社はこれらのデータを参照しないため、当社による二次利用や分析は技術的に不可能です。

4. 第三者への提供・共有

当社は 利用者のデータを第三者に一切提供・共有しません。これは、端末内のデータをサーバーに送信していないため、第三者が技術的にアクセスできない構造であることに起因します。

本アプリは、サードパーティの広告 SDK、アクセス解析 SDK、トラッキング SDK を一切組み込んでおりません。

5. データの保存場所と保持期間

5-1. 保存場所

すべての利用者データは、利用者の 端末内（iOS / Android スマートフォンの内部ストレージ、具体的にはアプリ専用の localStorage および IndexedDB 領域）のみに保存されます。クラウド同期、外部バックアップ、サーバー転送は一切行われません。

5-2. 保持期間

端末内のデータは、利用者が次のいずれかの操作を行うまで端末内に保持されます。

  • 利用者がアプリ内のデータ削除機能を実行する（次項 6 を参照）
  • 利用者が本アプリを端末からアンインストールする
  • 利用者が端末の設定からアプリのデータをクリアする
  • 利用者がブラウザのストレージをクリアする（PWA 利用時）

当社は、これらの操作とは別に利用者のデータを保持し続けることはありません。サーバー側にはそもそもデータが存在しないため、当社側で「保持期間」という概念が技術的に発生しません。

6. データの削除方法

利用者は以下の方法で、いつでもご自身のデータを完全に削除できます。

6-1. アプリ内からの削除（推奨）

本アプリでは、以下のいずれかの方法で記録データを削除できます。

  1. 個別の記録項目（写真・メモ・スコアなど）について、アプリ画面上の「削除」操作を行う
  2. 「Me（マイページ）」タブ内の「すべてのデータを削除」ボタンを使用する（本アプリで端末内に保存されたすべての記録データを一括削除します）

6-2. 端末設定からの削除

下記の方法でもデータを削除できます。

  • iOS: 設定アプリ > 一般 > iPhone ストレージ > 「ゆっくりエクソソーム」 > App を削除
  • Android: 設定アプリ > アプリ > 「ゆっくりエクソソーム」 > ストレージとキャッシュ > ストレージを消去（または「アンインストール」）
  • Web ブラウザ（PWA）: ブラウザの設定からサイトデータ（localStorage / IndexedDB）をクリア

6-3. 削除リクエストのお問い合わせ

当社はサーバーに利用者データを保持していないため、当社による削除作業は技術的に不要かつ不可能です。削除手順についてのサポートが必要な場合は、本ポリシー末尾の連絡先までご相談ください。

7. カメラ・写真ライブラリへのアクセス

本アプリは、利用者がビフォーアフター写真を記録する機能を任意で使用する際にのみ、以下の権限の許可を求めます。

  • カメラ: 肌や目元の状態変化を記録するため、新しい写真を撮影する場合に使用します。例: 今日の肌コンディションを撮影し、1か月後に同じ部位を撮って比較します。
  • 写真ライブラリ（読み取り）: 既存の写真を取り込んで「ビフォー写真」として使用する場合に使用します。例: 先月撮影した目元の写真を選んで、今日の写真と並べて比較します。
  • 写真ライブラリ（書き込み）: アプリで撮影した記録写真を端末の写真アプリへ保存する場合に使用します。例: 担当医に見せるためにエクスポートします。

撮影・選択された写真は、利用者の端末内（IndexedDB）にのみ保存され、当社のサーバーや第三者に送信されることは一切ありません。これらの権限は、利用者の端末の設定からいつでも変更（拒否・取り消し）できます。

8. 通知（プッシュ通知 / ローカル通知）

本アプリは、利用者が任意で設定する「毎日のセルフケアリマインダー」のために、端末のローカル通知機能を使用する場合があります。通知の内容は端末内で生成され、当社のサーバーから配信されるものではありません。利用者は端末の設定からいつでも通知を無効にできます。

9. 子どもの個人情報の取り扱い

本アプリは13歳未満の児童を主たる対象とした設計にはなっておりませんが、年齢制限を「4+」として App Store / Google Play に申請しており、保護者の同意のもとであれば利用は可能です。本アプリは収集データを一切持たない設計のため、児童のオンラインプライバシー保護法（COPPA）等にも適合します。

10. プライバシーポリシーの変更

本ポリシーの内容を変更する場合があります。重要な変更は、本ページの「最終更新日」を更新するとともに、必要に応じてアプリ内通知や公式 X（旧 Twitter）等を通じてお知らせします。
