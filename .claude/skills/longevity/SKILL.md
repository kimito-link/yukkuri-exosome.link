# 健康長寿コンテンツの執筆・点検スキル

このスキルの目的はひとつ。**言えることは強く言い、言えないことは言わない。**

盛った表現は短期の反応を稼ぐが、監修者・医師・専門家が読んだ瞬間に信用を失う。逆に正確な表現は、詳しい人ほど「分かっている」と評価する。ここが読者層の中心である以上、精度が売りになる。

---

## 1. まずエビデンスの段に仕分ける

書こうとしている主張が、どの段にあるかを最初に確定する。段によって使える語尾が変わる。

### A段：ヒトの介入研究がある（強く言ってよい）

- 睡眠不足がレプチン低下・グレリン上昇・インスリン感受性低下を招くこと
- 運動、禁煙、摂取エネルギー収支が体重に与える影響
- 血圧・血糖・脂質の管理と心血管イベントの関係

→ 語尾：「報告されています」「分かっています」「示されています」

### B段：ヒトの観察研究が中心（条件付きで言える）

- 食事パターン（地中海食など）と死亡率の関連
- 睡眠時間と死亡率のU字型の関連
- 社会的つながり、筋力・歩行速度と予後の関連

→ 語尾：「関連が報告されています」「〜という傾向が観察されています」
→ 必須：相関であって因果ではないことを一度は書く

### C段：動物・細胞・小規模研究が中心（断定禁止）

- オートファジーと断食時間の関係（多くは酵母・マウス由来）
- NMN / NAD+ / スペルミジン / セノリティクス
- **エクソソーム・培養上清の作用**
- グリンパティック系による脳内老廃物の排出

→ 語尾：「〜と考えられています」「研究が進められている段階です」
→ 必須：ヒトでどこまで確かめられているかを明示する

### D段：誤り（訂正して載せる）

第3節の対応表を参照。消すのではなく、**誤解として取り上げて正す**のが最も価値が出る。

| テーマ | 段 | 落としどころ |
|---|---|---|
| オートファジー | C | 分裂ではなく分解と再利用。大隅良典博士の2016年ノーベル賞は仕組みの解明に対するもので、健康効果の証明ではない |
| 断食・空腹時間 | C | 時間の数字はヒトで確定していない。体重が減る理由は摂取エネルギーの減少 |

## 3. 誤解 → 正しい言い換え

出てきたら必ず置き換える。左をそのまま書かない。

| よくある言い方 | 置き換え |
|---|---|
| オートファジーで細胞分裂が活性化して若返る | 分裂させる仕組みではありません。細胞の数が増えるのではなく、いまある細胞の中身が入れ替わります |
| 細胞分裂が進むほど若返る | 体細胞が分裂できる回数には上限があります（ヘイフリック限界）。分裂は維持の作業であって、巻き戻しではありません |
| オートファジーが脂肪を燃やす | 分解の対象は細胞内の古い部品で、体脂肪ではありません。空腹が続くと両方の状態が同じ条件下で重なるため混同されやすいところです |
| ◯時間断食すればスイッチが入る | 時間の根拠の多くは酵母や動物の実験に由来します。ヒトで何時間から、どの臓器でどれだけ起きるかは分かっていません |
| 寝ている間に細胞分裂が活性化して痩せる | 睡眠中に強まるのは修復と片づけです。体重に関わるのは分裂ではなく食欲ホルモンで、睡眠不足でレプチンが下がりグレリンが上がることが報告されています |
| エクソソームが細胞を修復する／若返らせる | 受け取った細胞のふるまいに影響すると考えられています |
| 培養上清には成長因子がたっぷり入っているので効く | 分泌された成分が含まれます。何がどれだけ働くのかは研究が進められている段階です |
| 天然由来だから安全 | 由来と安全性は別の話です |

## 4. 睡眠と体重（このジャンルで最も盛られやすいので独立させる）

「寝るだけで痩せる」は最も需要があり、最も誇張される。**言えることは意外と多く、しかも A段で強く言える。**盛る必要がないので、正確に書くほうが強い。

### 何がどこまで言えるか

| 主張 | 段 | 書き方 |
|---|---|---|
| 睡眠不足でレプチン（満腹のサイン）が下がり、グレリン（空腹のサイン）が上がる | **A** | 「報告されています」と言い切ってよい |
| 睡眠不足の翌日は食欲、とくに高カロリーのものへの欲求が増える | **A** | 同上。介入研究がある |
| 睡眠不足でインスリン感受性が下がる | **A** | 同上。健康な人でも数日で起きる |
| 短い睡眠と肥満・体重増加の関連 | **B** | 観察研究中心。**相関であって因果ではない**と必ず添える |
| 睡眠時間と死亡率のU字型（長すぎも短すぎも） | **B** | 「関連が観察されています」。長時間睡眠は原因ではなく体調の反映という見方もある |
| 寝ている間の消費エネルギーを増やして痩せる | **D** | 誤り。下の表で訂正する |
| 睡眠で細胞分裂が活発になって痩せる | **D** | 誤り。分裂と体重は別の話 |

### 誤解 → 言い換え（睡眠×体重）

| よくある言い方 | 置き換え |
|---|---|
| 寝るだけで痩せる／睡眠ダイエット | 眠ること自体が体脂肪を減らすわけではありません。睡眠不足のときに食欲のサインが乱れることが分かっていて、**整えると食べ過ぎにつながりにくい**、という順序です |
| 寝ている間に脂肪が燃える | 睡眠中も代謝は続きますが、消費エネルギーは起きているときより下がります。「寝るほど燃える」ではありません |
| ゴールデンタイム（22〜2時）に寝ないと痩せない | 時刻そのものより、**十分な長さと規則性**のほうが確かめられています。成長ホルモンは入眠後の深い睡眠に合わせて出るので、時刻に固定されているわけではありません |
| 睡眠不足だと痩せない体質になる | 体質が変わるという言い方は避けます。**そのときの食欲と血糖の扱いやすさが変わる**、が実際に分かっていることです |
| 何時間寝れば痩せる | 体重が減る／増えるを決めるのは摂取と消費の収支です。睡眠はそこに**間接的に効く**要因のひとつ、という位置づけにとどめます |

### 書くときの順序（これを守れば盛らずに強く書ける）

1. **睡眠は体重を直接減らす装置ではない**とまず置く
2. 効くのは**食欲のサイン（レプチン・グレリン）**という経路だと説明する ← ここがA段
3. だから「痩せる」ではなく**「食べ過ぎにつながりにくくなる」**と書く
4. 体重の増減そのものは**摂取エネルギーの収支**であると一度書く
5. 数字（何時間・何kg）を約束しない

> 「寝れば痩せる」と言われることがあります。眠ること自体が脂肪を減らすわけではありません。分かっているのは、睡眠が足りないと満腹のサインであるレプチンが下がり、空腹のサインであるグレリンが上がることで、翌日の食欲が増えると報告されている、というところまでです。体重そのものは食べた量と使った量の差で決まります。

### 大幅に減量した個人の体験談を見たとき

「150kg→68kg」のような劇的な成功談は、SNS・YouTube で最も強く届く形式であり、**そこで語られた方法をそのまま採用したくなる**。ここが一番危ない入口なので、扱い方を決めておく。

- **1人の結果は、その人に起きたことであって、効いた理由の証明ではない。** 同時に何十個も変えているので、どれが効いたかは本人にも分からない
- **生存者バイアス。** 同じ方法で続かなかった人・体調を崩した人は動画を出さない。見えている分母が違う
- **大幅減量そのものは医学的に起こりうるし、否定しない。** 否定すべきなのは「だからこの方法が効く」という一般化のほう
- **極端な方法ほど語りやすい。** 「1日1食」「炭水化物を抜いた」は物語になりやすいが、再現性と安全性は別問題

**書くときの扱い:**

| やること | やらないこと |
|---|---|
| 「こういう方や例があります」と紹介にとどめる | 体験談を根拠にして方法を推奨する |
| 共通して確かめられている原則（収支・睡眠・継続）に戻す | 数字（−78kg・◯ヶ月）を期待値として提示する |
| 個人差と、持病・服薬がある場合の相談を添える | ビフォーアフターの画像・数値を単体で並べる |

> 「大きく減量した方の話は励みになります。ただ、その方に起きたことがそのまま同じように起きるとは限りません。多くの場合、同時にいくつものことが変わっているので、どれが効いたのかは本人にも切り分けられないのが実際のところです。」

**このアプリでは体験談を成果の根拠として載せない**（第5節「構造として危ないもの」と同じ理由）。

### このアプリで扱うときの注意

**肌の10段階セルフチェックと写真記録があるアプリで体重の話をする**ので、次を守る。

- 体重・体脂肪の**数値入力欄や目標値を作らない**（HANDOFF-20260824.md 第5章の除外方針と同じ理由）
- 「痩せ」を目的語にした見出しを作らない。**睡眠の話は睡眠の効用で完結させる**
- 睡眠不足の日を「失敗」として表示しない。整った日を数えるだけにする
- 摂食障害の可能性がある層に届く前提で書く。**食事を減らす方向の助言はしない**

## 5. 薬機法・医療広告ガイドラインの検出

### 使わない語

治る／完治／確実／絶対／最高／No.1／即効／必ず／驚異の効果／アンチエイジング効果がある／若返る／◯◯に効く／副作用がない／安全です

### 構造として危ないもの

- **ビフォーアフター写真を単体で出す** — 医療広告ガイドライン上、治療内容・費用・リスク・副作用の説明なしでは掲載できない
- **体験談を効果の根拠として使う**
- **特定の商品・施術を推奨する導線**
- **他と比べて優れているという比較優良**
- **「今だけ」「限定」など受診を煽る表現**
- **商標**（U-Factor® など）や**地域名を含むクリニック特定情報**

### 数値イメージの扱い

体内マップの点灯や「＋◯粒」のような演出には、**実測値ではない旨の注記を必ず添える**。

## 6. 点検の手順

1. 主張をすべて抜き出し、A〜Dのどの段かを1つずつ判定する
2. C段のものに断定語尾が残っていないか確認する
3. 第3節の対応表に一致する言い方がないか検索する
4. 第5節の禁止語と危険な構造を検出する
5. 「医療機関でご相談ください」に相当する一文があるか確認する
6. 最後に読み返して、**専門家が読んだときに引っかかる箇所がないか**を見る

## 7. 書くときの型

誤解を先に置き、正しい姿を後に置く。この順が最も伝わる。

> 「〇〇と言われることがあります。実際には△△です。分かっているのはここまでで、□□については研究が進められている段階です。」
